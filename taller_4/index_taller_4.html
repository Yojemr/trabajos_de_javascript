Punto 3

Desarrollo de un Sistema Automatizado de Nómina Web Una empresa requiere una aplicación web para automatizar el cálculo de la nómina mensual de sus trabajadores. Las condiciones laborales y políticas de pago se estructuran bajo los siguientes parámetros: Jornada Laboral y Salario Base: El empleado cumple una jornada de 48 horas semanales. La tarifa base inicial se establece en $6.471 por hora, valor que puede ser modificado según el contrato. Auxilio de Transporte: Se otorgará este beneficio únicamente si el salario bruto del trabajador es inferior a dos (2) salarios mínimos legales vigentes (SMLV). Horas Extras: Debido a la fluctuación en el flujo de pedidos, el empleado acumula mensualmente una cantidad variable de horas extras diurnas. Deducciones Fijas: Se aplica un descuento del 3% sobre el salario bruto para el servicio de EMI y un 2% destinado a la mensualidad de la funeraria. Deducciones Variables: El sistema debe permitir ingresar un valor variable correspondiente al aporte voluntario del fondo de empleados. Demandas por Alimentos: El trabajador registra una novedad por demanda de alimentos. Si su salario bruto mensual supera los $3.740.000, el sistema deberá aplicar automáticamente una retención equivalente al 30% del salario bruto por este concepto. Requerimiento Técnico: Desarrollar una interfaz web (HTML y JavaScript) que reciba las variables de entrada y procese la liquidación. La aplicación debe calcular y desplegar en pantalla de forma clara: el salario bruto mensual, el desglose y total de las deducciones aplicadas, el estado detallado de la demanda de alimentos, y el salario neto definitivo a pagar.

Punto 5

En una entidad bancaria se brinda a los usuarios diferentes servicios y dependiendo de lo que requiera, la máquina dispensadora le genera un ticket con un consecutivo y lo direcciona para el área requerida. Se sabe que el menú de opciones ofrece 5 posibilidades: Si el usuario va para el servicio de caja, selecciona la opción 1 Si va para servicio al cliente selecciona la opción 2. Si va para pago de impuestos elige la opción 3. Si se dirige para crédito hipotecario, presiona la opción 4. Cuando el usuario requiera realizar operaciones con tarjeta de crédito debe elegir la opción 5. En caso de que el usuario elija una opción que no esté en el menú, el sistema debe mostrar un mensaje que diga “Opción no válida”. Recuerde que el sistema debe imprimirle al usuario: el número del Ticket, Id de la sucursal, para qué servicio va y la fecha y hora actual.
